## Inside ELAN

ELAN is a local Windows annotation app with a named elan desk, a short tier list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside recordings you already own and holds only the tier that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra tiers wait for their own title. ELAN starts with a local profile and does not need a complex account system.
